## Praktikum 2
1. Pada Langkah ke-2, setelah membuat proyek baru menggunakan Next.js, terdapat beberapa istilah yang muncul. Jelaskan istilah tersebut, TypeScript, ESLint, Tailwind CSS, AppRouter, Import alias, App router, dan Turbopack!

   TypeScript = menambahkan tipe statis ke JavaScript untuk mencegah bug dan meningkatkan struktur kode
   ESLint = alat untuk memastikan kode bersih dan sesuai aturan best
   Tailwind CSS = Framework CSS berbasis utility untuk desain yang cepat dan flesibel
   AppRouter = Sistem routing berbasis folder baru di Next.js
   Import alias = Mempermudah impor file tanpa menggunakan jalur panjang
   App router =
   Turbopack = Bundler generasi baru yang lebih cepat dibanding Webpack.
        
3. Apa saja kegunaak folder dan file yang ada pada struktur proyek React yang tampil padagambar pada tahap percobaan ke-3!
   - .next/ = hasil build dan cache
   - app/ = berisi komponen halaman(page.tsx), layout.tsx dan folder route-based
   - node_modules/ = menyimpan semua dependensi (library dan package)
   - public/ = menyimpan file statis seperti gambar, ikon, dan aset lain
   - .gitnore file atau folder yang ingin diabaikan oleh Git saat melakukan commit
   - eslint.config.mjs = memastikan kode tetap bersih dan sesuai standar best           practice
   - next-env.d.ts = memastikan Next.js dapat bekerja dengan TypeScript dengan baik
   - next.config.js = pengaturan seperti import, fitur experimental, konfigurasi server-side rendering dan static generation
   - package-lock.json = dafrtar dependensi proyek
   - postcss.config.mjs = konfigurasi POstCSS, yang sering digunakan bersama Tailwind CSS untuk mengoptimalkan CSS
   - tailwind.config.ts = mengatur tema, warna dan fitur lain
   - tsconfig.json = Konfigurasi TypeScript dalam proyek
